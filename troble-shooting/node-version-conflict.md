# nvm으로 Node 버전을 변경했지만 적용되지 않는 문제

## 문제 상황

nvm use 16.14.2 실행 후에도
node -v 결과가 기존 버전(v20)으로 출력되었다.

## 원인 분석

터미널 PATH 우선순위가
기존 Node 설치 경로를 먼저 참조하고 있었다.

nvm이 정상적으로 적용되지 않은 상태였다.

## 해결 과정

- 컴퓨터 재부팅
- node -v 명령어로 확인
- 16.14.2 버전 적용됨

## 결과

node -v 결과가 정상적으로 변경되었다.

## 배운 점

버전 매니저 사용 시
실제 실행 경로(PATH)를 확인하는 습관이 중요하다고 느꼈다.
